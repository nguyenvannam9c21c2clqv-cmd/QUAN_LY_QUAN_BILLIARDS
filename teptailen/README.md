# THƯ MỤC TỆP TẢI LÊN

## 1. Giới thiệu
Thư mục này dùng để quản lý các tệp tải lên của hệ thống quản lý quán Billiards.

## 2. Các loại tệp
- Hình ảnh bàn Billiards
- Hình ảnh sản phẩm
- Hình ảnh đồ ăn, nước uống
- Tài liệu liên quan đến hệ thống

## 3. Lưu ý
- Chỉ sử dụng các tệp hợp lệ.
- Không tải lên thông tin cá nhân nhạy cảm.
- Không lưu mật khẩu hoặc dữ liệu bí mật.
